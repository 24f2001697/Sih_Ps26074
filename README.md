# AgriSense AI

AI-Powered Weather Downscaling & Agro-Meteorological Advisory

### SIH 2026 — Problem Statement 26074

Downscaling of weather forecast from Block level to Panchayat level.

## Features

- AI-based Block → Panchayat weather downscaling
- Multi-source weather and GIS data fusion
- Panchayat-level rainfall and temperature predictions
- Uncertainty and confidence estimation
- Spatio-temporal weather analysis
- Agro-meteorological advisories
- Interactive weather dashboard
- Disaster alerts
- ML model workbench

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Python/ML backend (planned)
- GIS / Weather datasets
